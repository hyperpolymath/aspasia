= Architecture of aspasia

This document describes the layout of this repository as it actually
exists, per the estate Required Files gate (substance over presence).

== Layout

* `.devcontainer/` — .devcontainer — repository component
* `.github/` — GitHub workflows, labels and repository configuration
* `.hypatia/` — .hypatia — repository component
* `.machine_readable/` — .machine_readable — repository component
* `.reuse/` — .reuse — repository component
* `LICENSES/` — LICENSES — repository component
* `benches/` — benches — repository component
* `contractiles/` — estate contractile declarations
* `docs/` — documentation
* `examples/` — worked examples
* `ffi/` — ffi — repository component
* `generated/` — generated — repository component
* `src/` — primary source code
* `tests/` — test suites and fixtures
* `www/` — www — repository component

== Data flow

The entry points and the CI definition under `.github/workflows/` are the
authoritative description of how the pieces above fit together; where a
README exists at the root it narrates usage. This file intentionally
names only directories that exist here.
